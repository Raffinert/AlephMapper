# AlephMapper 0.8.3 — proposed release notes

This release improves generated-code correctness and generator reliability.

- Generated projections retain the original binding of static imports, aliases, generic type names, and namespace-local imports across partial mapper declarations.
- Distinct nested or otherwise colliding mapper types receive distinct generated file names. Existing file names remain stable when no generated mapper collides.
- Cancellation propagates through mapper analysis and emission instead of becoming a generator crash diagnostic.
- Nullable switch null checks use a nullable `object` cast when nullable annotations are enabled, avoiding incorrect CS8600 warnings.
- Regression and integration tests cover these cases, generated expression behavior, and warning-clean supported fixtures.
- A standalone benchmark records cold generation and incremental edit behavior without a CI timing threshold.

The existing null-rewrite behavior can still produce nullable receiver warnings when a receiver may be evaluated more than once. These warnings remain visible. This document describes the proposed package contents; it does not indicate that a package has been published.
