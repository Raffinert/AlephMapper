# v0.8.0 release notes - unpublished draft

- Add CSharp14 extension-block instance methods and expression-bodied getter
  properties to static Projectable factories, with symbol-aware composition.
- Add AM0021 for unsupported requests, signature conflicts and inaccessible
  dependencies; existing switch/null diagnostic contracts remain unchanged.
- Preserve receiver/argument conversions, nested lambda scopes, static dependencies,
  original nameof results and classic extension method behavior.
- Versioned analyzer assets restore/broaden compiler-host compatibility: classic
  mappings on Roslyn4.8+, CSharp14 extensions on Roslyn5.0+. NuGet automatically
  selects one compatible asset. Both variants target netstandard2.0. Actual4.8,
  4.14,5.0 and SDK5.9 compiler processes are covered by package runtime tests.
- Incorporates PR56 switch and helper-inlining improvements in dev_v0_8_0.

No version bump, release, tag, NuGet publish or main integration was performed.
The feature PR requires explicit owner approval before merge.
